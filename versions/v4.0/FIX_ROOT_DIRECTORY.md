# 🔧 Исправление ошибки "Could not find root directory: /versions/v4.0"

## Проблема
Railway ищет `/versions/v4.0` как абсолютный путь, но это неправильно.

## Решение

### Шаг 1: Проверьте настройки Root Directory в Railway Dashboard

1. Откройте https://railway.app
2. Проект → **"peaceful-dedication"**
3. Сервис → **"SPIN-Training-BOT-Final"**
4. Перейдите в **Settings** → **Build & Deploy**
5. Найдите раздел **"Root Directory"**

### Шаг 2: Исправьте Root Directory

**Вариант A: Если Root Directory установлен в `/versions/v4.0`**
- Удалите это значение (оставьте пустым)
- ИЛИ измените на `versions/v4.0` (без начального слеша, относительный путь)

**Вариант B: Если Root Directory пустой**
- Установите значение: `versions/v4.0` (без начального слеша)
- Это относительный путь от корня репозитория

**Вариант C: Если ничего не помогает**
- Удалите Root Directory полностью (оставьте пустым)
- Railway будет деплоить из корня репозитория
- Но тогда нужно убедиться, что все файлы в корне

### Шаг 3: Сохраните и перезапустите

1. Сохраните изменения в Dashboard
2. Railway автоматически перезапустит деплой
3. ИЛИ нажмите "Redeploy" вручную

## Альтернативное решение

Если настройка Root Directory не помогает, можно:

1. **Скопировать файлы в корень репозитория** (временно для деплоя)
2. **Или использовать другой подход** - деплой из корня с правильными путями

## Проверка

После исправления Root Directory:
- Railway должен найти файлы
- Деплой должен пройти успешно
- В логах должно быть: "Monkey-patched asyncpg.connect to filter sslmode parameter"
